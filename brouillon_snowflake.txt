Spark a produit plusieurs fichiers Parquet au fil des traitements, en raison du fonctionnement de Structured Streaming. 
Ce n'est pas un problème. Snowflake sait charger plusieurs fichiers simultanément avec COPY INTO.
Mais nous allons d'abord envisager une consolidation des fichiers avec Spark pour obtenir trois datasets Parquet plus compacts.

Nous avons 427 fichiers pour seulement 1 Mo de données !
C'est un exemple intéressant du problème des Small Files dans les architectures Big Data.
Pourtant dans un environnement de production, un trop grand nombre de petits fichiers peut entraîner :
- davantage d'opérations de lecture ;
- une surcharge liée à la gestion des métadonnées ;
- une dégradation des performances lors des traitements.
C'est pourquoi nous allons consolider d'abord ces fichiers (Lire les trois datasets Gold, Afficher leur schéma, Calculer leur nombre de lignes,Consolider les fichiers avec coalesce(1), Écrire les nouveaux fichiers dans snowflake_export).
coalesce(1) fonction permet de réduire le nombre de partitions avant l'écriture en un seul fichier Parquet par dataset.

Attention : ce choix est adapté à nos petits volumes. Sur des datasets de plusieurs centaines de Go, nous ne chercherions évidemment pas à tout concentrer dans une seule partition.

Test de not_null sur tous les champs dans schema.yml
Puis tests personnalisés :
- d'unicité produit + fenêtre temporelle : un produit ne doit apparaître qu'une seule fois par fenêtre.
- d'unicité utilisateur + fenêtre temporelle : un utilisateur ne doit apparaître qu'une seule fois par fenêtre.
- de non-négativité des métriques : les compteurs et montants ne doivent jamais être négatifs (métriques sources + ratios calculés des trois modèles Intermediate).
- de cohérence entre les compteurs d'événements (Parce que chaque vue, ajout au panier ou achat est un événement. Ces compteurs ne devraient donc jamais dépasser le nombre total d'événements de leur groupe.).

    New-Item -ItemType Directory -Force -Path "secrets\snowflake"
    python -c "from cryptography.hazmat.primitives.asymmetric import rsa; from cryptography.hazmat.primitives import serialization; from pathlib import Path; p=Path('secrets/snowflake'); key=rsa.generate_private_key(public_exponent=65537,key_size=2048); (p/'rsa_key.p8').write_bytes(key.private_bytes(serialization.Encoding.PEM,serialization.PrivateFormat.PKCS8,serialization.NoEncryption())); (p/'rsa_key.pub').write_bytes(key.public_key().public_bytes(serialization.Encoding.PEM,serialization.PublicFormat.SubjectPublicKeyInfo)); print('RSA key pair generated successfully.')"
