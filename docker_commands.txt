Notre PostgreSQL contient 3 data products Gold :

Table	              Grain	                            
gold_hourly_metrics	1 ligne / heure
gold_product_metrics	1 ligne / produit / heure
gold_user_metrics	1 ligne / utilisateur / heure

Le grain est une notion importante 

Par exemple : gold_product_metrics -> une ligne représente un produit pendant une fenêtre horaire donnée.

La clé primaire le confirme : (window_start, window_end, product_id)

Donc :

Produit 101 + 10h00-11h00 -> 1 ligne
Produit 101 + 11h00-12h00 -> 1 ligne
Produit 102 + 10h00-11h00 -> 1 ligne
